# Список замечаний к требованиям «Библиотека рецептов» v1.0

Итерация: 1
Проверяемый документ: iter_1/requirements_v1.0.odt
Роль проверяющего: исполнитель-тестировщик
Статус: замечания к согласованию с заказчиком
Замечание — вопрос по требованиям, требующий уточнения до начала реализации (нарушение критериев качества требований или наличие более простого/дешёвого/популярного решения).

## Полнота

**ZAM-01 · FR-04 «Поиск» · Однозначность, Полнота**
Поиск не определён: не указаны поля (название / ингредиенты / теги / шаги), тип совпадения (подстрока vs точное), учёт регистра, поведение при пустом запросе и пустом результате.
→ *Правка:* Задать поля поиска, подстрочное совпадение без учёта регистра, поведение при пустом вводе/результате.

**ZAM-02 · FR-05 «Фильтрация» · Полнота, Однозначность**
Фильтр только по категории; не указано, кто создаёт категории (система/пользователь), возможен ли множественный выбор, комбинируется ли с поиском и сортировкой.
→ *Правка:* Определить источник категорий, множественный фильтр, совместимость с поиском/сортировкой.

**ZAM-03 · FR-06 «Сортировка» · Полнота, Однозначность**
Не указаны поля сортировки (название / дата добавления / время готовки), направление и сортировка по умолчанию.
→ *Правка:* Перечислить поля, направление, значение по умолчанию.

**ZAM-04 · FR-01, FR-02 · Полнота**
Не определены обязательные и необязательные поля рецепта, их типы и ограничения (длина названия, число ингредиентов/шагов, допустимые символы).
→ *Правка:* Задать структуру рецепта и ограничения полей.

**ZAM-05 · FR-01, FR-07 · Полнота**
Нет требований к валидации ввода; не определено поведение при пустом названии, пустом списке ингредиентов, дубликатах названий.
→ *Правка:* Задать правила валидации и обработки дубликатов.

**ZAM-06 · FR-08 «Удаление» · Полнота**
Не указаны подтверждение удаления, возможность восстановления (корзина), судьба фотографии и связей.
→ *Правка:* Задать подтверждение и/или корзину, обработку связанных данных.

**ZAM-07 · FR-11, FR-12 «Импорт/экспорт» · Однозначность, Полнота**
Не указан формат файла обмена (CSV/JSON/…), экспортируемый состав, поведение при конфликтах, дубликатах и ошибках импорта.
→ *Правка:* Зафиксировать формат (напр. JSON), состав, правила разрешения конфликтов и ошибок.

**ZAM-08 · FR-13 «Фотография» · Полнота, Реализуемость**
Не указаны допустимые форматы, максимальный размер, число фото на рецепт, обязательность, место хранения (файлы/БД).
→ *Правка:* Задать форматы (JPG/PNG), лимиты, способ хранения, поведение без фото.

**ZAM-09 · Раздел 4 · Полнота**
Не определён полный состав данных рецепта: категория, теги, время приготовления, число порций, единицы измерения ингредиентов.
→ *Правка:* Добавить перечень полей и их типы.

**ZAM-10 · FR-10 «Пересчёт порций» · Однозначность, Полнота**
Пересчёт неоднозначен: единицы измерения (масса / штуки / «щепотка»), базовое число порций, правило округления.
→ *Правка:* Задать базовые порции, поддерживаемые единицы, правила округления.

## Проверяемость / однозначность

**ZAM-11 · NFR-01 · Проверяемость, Однозначность**
«Работать быстро» не измеримо.
→ *Правка:* Задать метрики времени отклика (напр. список ≤ 1 с, поиск ≤ 2 с при 10 000 рецептов).

**ZAM-12 · NFR-03 · Проверяемость, Однозначность**
«Должно быть удобным» субъективно и не проверяемо.
→ *Правка:* Заменить измеримыми требованиями (число действий до ключевых операций) либо перенести в цели.

**ZAM-13 · NFR-04 · Реализуемость, Проверяемость**
«Произвольное количество рецептов» нереализуемо и не проверяемо.
→ *Правка:* Задать целевой объём (напр. до 10 000 рецептов).

**ZAM-14 · NFR-05 · Необходимость, Проверяемость**
Пересекается с NFR-02 и не проверяемо без сценария.
→ *Правка:* Объединить с NFR-02 либо задать сценарий «все функции доступны без сети».

**ZAM-15 · Раздел 3 · Однозначность**
«Персональный компьютер» не определяет ОС и тип приложения (десктоп/веб/консоль).
→ *Правка:* Указать целевую ОС и тип приложения.

**ZAM-16 · Раздел 2 · Однозначность**
Термины «категория» и «тег» не разграничены.
→ *Правка:* Дать чёткие определения и разграничение.

**ZAM-17 · Раздел 2 · Полнота**
Не указаны язык интерфейса, локализация, система единиц измерения.
→ *Правка:* Задать язык (русский) и метрические единицы.

## Полнота (пробелы по нефункциональным)

**ZAM-18 · FR-09 «Избранное» · Полнота**
Не указано, как избранное отображается/фильтруется и влияет ли на сортировку.
→ *Правка:* Описать представление избранного (отдельный раздел/фильтр).

**ZAM-19 · Раздел 5 · Полнота**
Нет требований к надёжности: сохранность данных при сбое, резервное копирование, целостность.
→ *Правка:* Добавить требования к сохранности и целостности данных.

**ZAM-20 · Раздел 5 · Полнота, Безопасность**
Нет требований к приватности/защите персональных данных.
→ *Правка:* Зафиксировать локальное хранение без выгрузки данных наружу.

## Приоритизация / трассируемость

**ZAM-21 · Разделы 4, 5 · Приоритизация**
Шкала приоритетов не определена (что означают «Высокий/Средний/Низкий»).
→ *Правка:* Дать определение шкалы.

**ZAM-22 · Весь документ · Трассируемость**
Нет критериев приёмки и прослеживаемости требований к целям/пользовательским историям.
→ *Правка:* Добавить цели, критерии приёмки и таблицу трассируемости.
